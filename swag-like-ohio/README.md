# Swag like Ohio

UMDCTF 2025, OSINT. A photo of a bridge somewhere in Ohio; the flag is its address.

## Solve

Reverse image search on the bridge returned the Putnam Street Bridge in Marietta, Ohio, which
crosses the Muskingum River. Its address is Putnam Street, Marietta, OH 45750.

## Flag

```text
UMDCTF{Putnam Bridge, Marietta, OH 45750}
```

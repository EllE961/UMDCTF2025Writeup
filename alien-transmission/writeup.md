# Alien Transmission

## Challenge
> We've intercepted a signal from an alien planet! The image appears to be distorted and blurry. Can you recover the hidden message to see if aliens are suffering from the same brainrot as us?

## Files
- `output.png` - Blurred image generated by applying a convolution kernel
- `gen.py` - The script used to generate the output image

## Solution
The challenge provided a blurred image created using a convolution operation with a random kernel. To recover the flag:

1. Reconstructed the kernel using the same random seed (420)
2. Applied a **center boost** to the kernel (multiplied the center 3×3 region by 1.5)
3. Convolved the green channel with this modified kernel
4. Inverted the result (255 - pixel value)
5. Applied contrast enhancement (factor 1.80)

The key insight was modifying the kernel's center region to reverse the blurring effect.

## Flag
`UMDCTF{gl33p_gl0rp}`

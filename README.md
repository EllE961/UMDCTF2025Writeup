# UMDCTF Challenges

This repository contains my solutions to various challenges from the UMDCTF competition.

## Overview

Each directory corresponds to a different challenge that I solved, containing the challenge files and my solution. Most directories include a writeup explaining the approach I took to solve the challenge.

## Tools Used

- Python for scripting and analysis
- Various cryptographic tools
- Image processing libraries
- Reverse engineering tools

## Flags

All flags follow the format `UMDCTF{...}`
